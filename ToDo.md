# ToDo — сайт для планшета вместо Telegram-бота

Стек: Vue 3 (`frontend/`) и FastAPI (`api/`). Логика учёта осталась в
`storage/db.py`; в нём изменено только логирование.

## 0. Каркас

- [x] FastAPI: сессии, защита от запросов с чужих сайтов, раздача собранного Vue
- [x] Vue 3 + Vite + vue-router, собственные стили без CDN (работает в локальной сети)
- [x] Запуск `python main.py` (uvicorn), журнал сервера в `data/logs/app.log`

## 1. Вход и роли

- [x] Вход по логину и паролю, без регистрации
- [x] Учётные записи `admin/admin` и `employee/employee` (простые — для проверки)
- [x] Логины и хеши паролей — в отдельной таблице `accounts`, таблица `users` бота не меняется
- [x] Ограничение попыток входа, сброс сессий после отключения доступа или смены пароля
- [x] `python main.py set-password ЛОГИН` — восстановить доступ
- [x] Администратор не может лишить себя прав: ни в «Сотрудниках», ни в редакторе базы

## 2. Интерфейс для планшета

- [x] Кнопки и поля не ниже 56 px, быстрые кнопки количества, «минус/плюс»
- [x] Roboto Mono: 18 / 22 / 28 px, вес 400 / 500 / 600
- [x] Плоские SVG-иконки (lucide) вместо цветных эмодзи
- [x] Сотрудник — узкое меню с крупными значками; администратор — тёмная панель
- [x] «Скоро испортится» (бывшее «Сегодня заканчивается срок») — сразу под «Главной»
- [x] На главной администратора нет «пользователей с доступом»
- [x] Даты — только календарём, на экране ДД.ММ.ГГГГ (перевод формата — на клиенте)
